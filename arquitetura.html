Importa audio_utils e ui_effects.
Ouve htmx:afterSwap · extrai HX-Trigger · despacha ui_commands[] para o mapa de ações.

Protocolo HX-Trigger

Backend → Frontend (header de resposta)

HX-Trigger: {
  "ui_commands": [
    { "action": "typeText",   "args": { "elementId": "...", "fullText": "...", "speed": 60,
                                        "postTypingCommand": { "action": "showElementById",
                                                               "args": { "elementId": "btn-iniciar-sistema" } } } },
    { "action": "playAudio",  "args": { "id": "trilha-sonora-1999", "acao": "trocar_trilha",
                                        "src": "/static/audio/Game_1999.mp3", "volume": 0.3 } },
    { "action": "loopAutomatico", "args": { "tempo_ms": 1500 } }
  ]
}
